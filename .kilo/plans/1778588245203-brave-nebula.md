### 2. SwordWeapon.cs - What to Implement

**Current `TryFire()` issues:**
- Calls `PerformAttack()` immediately but doesn't check if attack actually hits
- Heat should only apply on HIT (per `appliesToMeleeOnlyOnHit` flag in WeaponData)

**Required Changes:**

#### A. Modify `PerformAttack()` method:
1. Use `Physics.SphereCast` or raycast to detect actual hit point
2. Store hit information (transform position, direction)
3. Return list of enemies actually hit

#### B. Add Hit Detection Callback:
- Create method `OnHitEnemy(EnemyBase enemy, Vector3 hitPoint)`
- This method will:
  - Apply damage to enemy
  - Apply heat to weapon (`currentHeat += data.heatPerShot`)
  - Trigger visual effects (hit particles, recoil)
  - Spawn energy orb if enemy dies

#### C. Update `TryFire()` logic:
```csharp
protected override void TryFire()
{
    // Perform sphere cast / overlap check
    // If hits found:
    //   - For each unique enemy: call OnHitEnemy(enemy, hitInfo.point)
    //   - Heat applied per hit (not per TryFire call)
}
```

#### D. Update `ExecuteSkill()` logic:
- Skill for sword could be: "Block" or "Heavy Attack"
- If heavy attack: higher damage, more heat
- If block: temporary invulnerability, no heat

### 3. EnemyBase.cs - Already Complete ✅

## Detailed Method Breakdown

### SwordWeapon.cs New Methods:

1. **`PerformAttack()`** (modify existing)
   - Purpose: Detect enemies in attack range
   - Use `Physics.OverlapSphere` or `Physics.SphereCast`
   - Return hit information for damage application

2. **`OnHitEnemy(EnemyBase enemy, Vector3 hitPoint)`** (new)
   - Purpose: Apply damage and heat on actual hit
   - Call `enemy.TakeDamage(damage)`
   - Add heat if not already overheated
   - Check if enemy died, spawn energy orb
   - Trigger visual feedback

3. **`SpawnEnergyOrb(EnemyBase enemy)`** (new)
   - Purpose: Create orb at enemy position on death
   - Use `Instantiate(orbPrefab, enemy.transform.position, Quaternion.identity)`
   - Pass heal/cooldown values from weapon data or enemy data

4. **`ExecuteSkill()`** (modify existing)
   - Option A: Heavy Attack (2x damage, 3x heat, longer cooldown)
   - Option B: Block (invulnerability frames, no heat)

## Key Design Decisions:

1. **Heat on Hit vs Heat on Swing**
   - Current setup: `appliesToMeleeOnlyOnHit = false` in WeaponData
   - But SwordWeapon currently applies heat in TryFire (wrong for melee)
   - Should change to: heat only when actual hit occurs

2. **Damage Calculation:**
   - Base damage from `data.baseDamage`
   - Optional: Heat multiplier if weapon is in optimal zone
   - Formula: `damage = baseDamage * (heatMultiplier ?? 1f)`

3. **Heat Application:**
   - Each successful hit adds `heatPerShot` to current heat
   - Clamp to `[0, overheatThreshold]`
   - Check for overheated state
